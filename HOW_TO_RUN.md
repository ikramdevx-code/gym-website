# How to Run the Gym Project

## Development Mode (Recommended)

To run the project in development mode with hot reload:

```bash
npm run dev
```

Then open your browser and go to: `http://localhost:5173`

## Production Build

To build for production:

```bash
npm run build
```

## Preview Production Build

To preview the production build locally:

```bash
npm run preview
```

Then open your browser and go to: `http://localhost:4173`

## Important Notes

1. **Don't open `dist/index.html` directly in the browser** - This causes 404 errors because React Router needs a proper server to handle routing.

2. **Always use `npm run dev` for development** - This starts a local server that handles all routes correctly.

3. **For production deployment**, use services like:
   - Vercel (recommended - configuration already included)
   - Netlify (configuration already included)
   - Firebase Hosting
   - Any service that supports SPA routing

## Troubleshooting

If you see a 404 error:
- Make sure you're running the dev server (`npm run dev`)
- Don't open the HTML file directly from the file system
- Clear your browser cache and reload

## Project Structure

- `/src` - Source code
- `/public` - Static assets (favicon, logo, etc.)
- `/dist` - Production build output (generated by `npm run build`)
